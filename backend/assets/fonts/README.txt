Letakkan berkas font kustom di folder ini bila klinik ingin memakai huruf sendiri
pada kwitansi PDF. Nama berkas yang dikenali (pilih salah satu ekstensi .ttf/.otf/.woff):

  Regular.ttf     -> teks biasa
  Bold.ttf        -> teks tebal
  Italic.ttf      -> teks miring

Bila folder ini kosong, sistem memakai font Inter (lisensi SIL OFL) yang
sudah disertakan, lalu font sistem sebagai cadangan terakhir.

Catatan: font WAJIB tertanam di dalam PDF agar keluaran memenuhi standar
arsip PDF/A. Gunakan font yang lisensinya mengizinkan penyematan (embedding).
